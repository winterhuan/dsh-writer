# 写短篇

作者指定盐言、付费点等平台网文写法，或要求接着做已有的平台短篇项目时，读取[平台短篇写作](platform-workflow.md)，从对应阶段继续。已有作品以书内定下的写法为准。单独管理作者习惯时按[作者记忆](references/author-memory.md)办理。

## 独立短篇

只聊构思、只列大纲或只提意见时，交付作者点名的内容。作者要成稿时按给定的题意、篇幅和视角直接写到结尾。零散素材也可以起笔，由作者留白的地方自行取舍。新作缺省在对话里交稿。作者指定作品目录、要求保存或正在续写书稿时，读该书已有的设定、大纲和正文，将稿件写入约定位置（工作台短篇为 `正文.md`）。已有作者偏好或本书文风时按[文风约定](references/style-resolution.md)处理。

从人物此刻想办的一件事写起。让读者看到人物凭什么做出选择，以及这一步怎样改变了另一个人的处境。也可以写一个人直到最后仍然弄错了什么，但读者应能从正文看见让他误会的依据。叙述声音、段落长短和是否揭开谜底随作品决定。

交稿前只看正文，从头读到最后。把真正影响理解的时间、物件去向、人物知情先后对起来。遇到人物突然改口、让步或认出某人，回到前文找他当时看到的东西。缺了关键一笔就在现场补，已经能读懂的地方留给读者。修订已有稿件时保留未被要求改动的段落和已经成立的细节。

按作者约定的篇幅与格式交付。作者要全文时给题名和正文，写作说明留给请求讲评的时候。
