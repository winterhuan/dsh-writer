# 黑岩官网：书库采集与分析

作者选择黑岩时读取。官网是 [黑岩网](https://www.heiyan.com/)，采集入口为[公开书库](https://www.heiyan.com/all.html)，无需管理后台账号。默认使用 Box，也可用 `--browser ego` 选择 Ego，环境检查见 `/browser-cdp`。

书库包含长短篇。列表顺序不是热度名次，页面「总点击」是累计值；不能据此判断近期热度、付费表现或短篇风口。短篇研究先按实际字数和完结状态筛选，不能把字数少的连载自动当成短篇；书库没有男频/女频字段。

## 页面与命令

```bash
node scripts/heiyan-booklist-scraper.js --pages 2 --outdir {输出目录}
node scripts/heiyan-booklist-scraper.js --browser ego --pages 1 --detail --outdir {输出目录}
```

默认最多采 5 页，当前官网每页 100 本；跟随页面「下一页」，没有下一页即结束。文件名为 `黑岩书库列表_all_{YYYYMMDD}.md`。`--channel male|female` 不适用于官网，脚本会提示去掉该参数。

`--detail` 逐本读取官网公开作品页的分类、完结状态和简介摘要，每次请求间隔至少半秒，远程执行还有通信耗时。先用一页验证；需要按完结状态筛短篇或分析题材时再采详情。官网简介可能不完整，不补造标签或隐藏内容。

## 字段与分析

- 列表：书名、作者、字数、总点击、更新时间、可打开的官网作品链接。
- 详情：官网公开分类、完结状态、简介摘要。列表未提供分类时记为「未分类」。
- 聚合保留「总点击」名称，不转换成阅读数或近期热度；黑岩默认采用通用字数分段。确认输入只含短篇后，可显式给聚合脚本传 `--scale short`。
- 更新时间不能当成新书创建时间。跨期比较需使用相同筛选与采集范围。

## 采集出问题

页面结构异常、验证码或连接失败时停止并保留浏览器现场。先按 `/browser-cdp` 检查同一会话；需要人工处理时交接页面，用户完成后再接管。不要据此要求用户登录其他域名的后台。

后续页或详情失败时输出 `.partial.md`，保留已成功数据，不覆盖完整报告。续采保留原参数，并传 `--resume <runId>`；需要接回浏览器时同时传 `--space <id>`。官网解析器与旧来源的检查点不兼容，不能混用。数据不足时报告缺项，不推断完整市场分布。
